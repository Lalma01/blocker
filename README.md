# PS-BLOCK

*Local content filter & screen-time guard*

[Magyar leírás lejjebb](#magyar)

**PS-BLOCK** is a Windows content filter and screen-time guard. It blocks adult
websites and NSFW-branded AI companion/image tools locally, while mainstream AI
assistants and general-purpose creative tools (ChatGPT, Claude, Gemini, Midjourney,
Canva, …) stay fully accessible. It monitors browser titles and lets you set a daily
screen-time limit. The interface follows your system light/dark theme, auto-detects
Hungarian vs. English on first run (switchable any time, with flags, right on the main
screen), and remembers your choice.

- Source code, build script and installer live in the [`Windows/`](Windows/) folder.
- Full documentation: [`Windows/DOCUMENTATION.md`](Windows/DOCUMENTATION.md).
- **Android port** (full feature parity): [`Android/`](Android/) — see [`Android/README.md`](Android/README.md).
- All filtering happens on the device — no data leaves the machine.

## Magyar

A **PS-BLOCK** egy Windows tartalomszűrő és képernyőidő-felügyelő alkalmazás. Helyben
tiltja a felnőtt oldalakat és az NSFW-jellegű AI társalgó-/képgenerátor eszközöket,
miközben a bevett AI asszisztensek és az általános célú kreatív eszközök (ChatGPT,
Claude, Gemini, Midjourney, Canva, …) teljesen elérhetők maradnak. Figyeli a böngészők
címsorát, és napi képernyőidő-korlát állítható be vele. A felület a rendszer
világos/sötét témáját követi, első indításkor automatikusan felismeri a magyar/angol
rendszernyelvet (bármikor átváltható, zászlókkal, közvetlenül a főképernyőn), és
megjegyzi a választást.

- A forráskód, a build szkript és a telepítő a [`Windows/`](Windows/) mappában található.
- Részletes dokumentáció: [`Windows/DOCUMENTATION.md`](Windows/DOCUMENTATION.md).
- **Android port** (teljes funkciójú): [`Android/`](Android/) — lásd az [`Android/README.md`](Android/README.md)-t.
- Minden szűrés a gépen történik — semmilyen adat nem hagyja el a számítógépet.
